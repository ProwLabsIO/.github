### Live Production Platform

#### [Prow // Red-Team](https://red-team.prowlabs.io) — Cloud-Orchestrated LLM & Multi-Modal Vulnerability Auditing
Self-serve adversarial evaluation and compliance grading engine purpose-built for production OpenAI-compatible (/v1/chat/completions) and private tunnel (/api/generate) endpoints.

* **41 Forensic Suites · 9 Failure Modalities:** Strict 1-to-1 coverage across Adversarial & Exfil, Sycophancy & Deception, Multi-Hop & State, Quantitative Math, Policy Precedence, Multi-Modal CAD Vision (8 blueprint/spatial-clash suites), Temporal & Routing, Hallucination & Sources, and Distractor & Slang.
* **21 Native Enterprise Formats:** Multi-document ingestion across .pdf, .docx, .xlsx, .pptx, .odt, .eml, .json, .yaml, .csv, system logs, and lossless 2048px PNG CAD renders.
* **3-Role Evaluation & Deterministic Interlocks:** Separates Primary, Vision, and Judge model routing with deterministic Python rules on standalone security vectors and Per-Trap Chain-of-Verification on multi-file suites.
* **Zero-Storage Volatile Pass-Through:** Target prompts, bearer API keys, and model responses execute strictly in ephemeral memory and are never logged or retained. Downloads a 6-artifact .zip forensic bundle (PDF, MD, JSON, CSV, TXT).
